## 2. Space / Nature / Science / Animals walata amathara category ekak add karanne kohomada?

**Separate category file ekak, JavaScript edit ekak, nathnam teacher upload button ekak one naha.** Catalogue eke model entry ekata aluth `category` name eka dunnama tab eka automatically hadenawa.

Example: **Vehicles**.

### Step A — model eka upload karanna

Owner widihata `car.glb` file eka repository eke **`public/models/`** athulata upload karanna. File name/capital letters match wenna one.

### Step B — catalogue entry eka add karanna

`public/models/catalog.json` edit karanna. **Aluth entry eka existing `models` array eka ATHULATA add karanna; file eke root `}` ekata passe append karanna epa.** Entries athara comma ekak one.

Complete, valid JSON example below. **This is an example only:** `car.glb` me patch eke include karala naha; oyage actual car model eka upload karala, actual filename/name/ID use karanna. This example keeps Animals and adds Vehicles alongside it.

### Step C — commit saha refresh

Commit → latest Pages workflow green → website hard refresh. Now tabs include **Space, Nature, Science, Animals, Vehicles**. Teachers select Vehicles and use Car; they do not need GitHub access or an upload button.

**Note:** a new category needs **at least one valid catalogue entry**. The tab is based on metadata; a missing GLB can still produce a tab/card but will give a loading error, so upload the actual file too. Empty category tabs are not created.

### More categories

Use any appropriate label, up to 24 characters:

- `Buildings`
- `Human Body`
- `History`
- `Geography`
- `Mathematics`

Put all models belonging to one category under the **same exact label**. `Vehicles` and `vehicles` would otherwise be different labels. Each model still needs a **unique, permanent ID**. Never change an existing ID just to rename its display category.

**Do not move the only Animals model into a new category if you want to keep the Animals tab.** For example, moving Velociraptor from Animals to Dinosaurs would remove Animals when no other model uses Animals. Add another model for an additional category, or deliberately recategorise the library knowing that effect. Space/Nature/Science also contain the built-in models.

## 3. Owner rules

- Teachers only see the curated model library and scene publishing tools. Keep catalogue/upload instructions in repository documentation, not the teacher app.
- Only add content you have rights to distribute/use commercially. A public model download or a licence that permits personal use is not automatically permission for a paid teacher product.
- Public Pages GLB files can be downloaded by visitors. Hiding an owner guide is **not DRM or access control**. Authentication, payments, licensing enforcement, private asset storage and permanent cloud publishing were not added in this update.
- Existing local-storage and snapshot-link limitations remain: clearing browser storage can remove projects; old links need the same hosted app/model files. Share a new snapshot after scene edits.
- Keep old published GLBs online. For a new immutable model version, use a new ID/filename instead of replacing an old referenced file.
- Use self-contained GLB 2.0, embedded PNG/JPEG textures, phone-friendly geometry. Draco/Meshopt are supported; KTX2 and external texture/buffer files are not. Full export settings: [ADD-MODELS.md](ADD-MODELS.md).
- Physical phone/printed-marker testing and a commercial production/privacy/accessibility review are still needed before selling at scale.
